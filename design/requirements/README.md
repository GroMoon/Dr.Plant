# 요구사항

- Doctor Plant의 기능 요구사항·명세를 모아둔다.
- 하위에 있는 메모는 요구사항 문서들 중 아직 미확정 된 부분, 고려해야할 부분들을 작성하여 업데이트 하며, 보고시 참고하도록 한다.

## 파일 규칙

- 파일명은 영어, 번호 접두사로 관리한다.
- 문서 제목은 영문, 내용은 한글로 쓴다.

## 메모

> 2026-09-20 `0.set/requirement.md` 구현(타이틀·설정·일시정지·입력) 중 확정이 필요한 항목.

- **일시정지의 "나가기" 대상이 불명확.** 지금은 *게임 종료*(확인 창)로 구현했다.
  타이틀로 돌아가는 경로가 요구사항에 없어 만들지 않았다. 타이틀 복귀 버튼이 필요한지 결정 필요.
- **"로딩" 항목이 비어 있음.** 씬 전환용 로딩 화면(페이드 + 진행률 바)만 만들어 두었다.
  로딩 중 보여줄 연출(일러스트·팁·로고) 미정.
- **저장소 슬롯에 표시할 정보 미정.** 로그 기능이 미구현이라 임시로 `챕터 / 플레이 시간 / 저장 일시`를 표시한다.
  덮어쓰기·삭제·자동 저장 UI는 넣지 않았다.
- **텍스트 크기 적용 범위.** 메뉴 레이아웃이 흔들리는 것을 피하려고 UI 전체가 아니라 *대사 텍스트*에만 적용했다(작게 18 / 보통 22 / 크게 28px).
- **텍스트 속도 범위.** 5~120자/초, 기본 40, 최대치는 "즉시"로 처리. 수치 확정 필요.
- **지원 언어.** 한국어·영어 2종을 코드 내 문자열 테이블로 관리 중이며, 영어 문구는 임시 번역이다.
- **해상도 목록.** 1280x720 / 1600x900 / 1920x1080 / 2560x1440 임시. 전체화면에서는 선택 비활성.
- **게임패드 매핑.** A=진행, B=취소, START=일시정지, 방향키·왼쪽 스틱=이동으로 임시 지정.
- **오디오 에셋 없음.** BGM·효과음이 없어 코드로 만든 임시 톤을 쓴다(`assets/audio/` 에 파일이 들어오면 자동으로 교체됨).
- **한글 폰트 에셋 없음.** 현재는 OS 폰트(맑은 고딕 등)를 사용한다. Steam 배포 전에 재배포 가능한 한글 폰트를 넣어야 한다.
- **챕터 1 본편 미작성.** `ch1/01.production.md` 가 비어 있어 시작하기의 도착지는 임시 씬(`chapter_stub.tscn`)이다.
