# 요구사항

Doctor Plant의 기능 요구사항·명세를 모아둔다.

## 파일 규칙

- 파일명은 영어, 번호 접두사로 관리한다: `00-overview.md`, `10-player.md`, `20-plant-system.md`
- 문서 제목과 내용은 한글로 쓴다.
- 각 요구사항에는 ID를 붙인다 (`REQ-PLANT-001` 형식, 영역은 영어 대문자).
  커밋 메시지·브랜치명에 그대로 쓸 수 있어 기획과 코드가 연결된다.

## 요구사항 작성 형식

```
### REQ-<AREA>-<번호> 제목

- **설명**: 무엇을 하는가
- **이유**: 왜 필요한가
- **완료 조건**: 어떤 상태면 끝난 것인가
- **상태**: 작성 전 / 확정 / 구현 중 / 완료
```

## 목차

|---|---|---|
| `00-overview.md` | 전체 개요 | 작성 전 |
