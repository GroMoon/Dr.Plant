### 로딩

### 비시각적 요소
- ESC 누를 시 일시정지 및 버튼 목록
	- 버튼 구성
		- 돌아가기
		- 설정(필요한 목록이며, 이는 UI,UX를 고려하여 자연스럽게 구현하도록 한다.)
			- BGM(슬라이더로 구현한다.)
			- 효과음(슬라이더로 구현한다.)
			- 화면 모드(창모드, 전체화면 및 해상도)
			- 언어 설정
			- 텍스트 속도, 텍스트 크기
		- 나가기
- 클릭 or 스페이스바 = 게임 진행
- 방향키
- 조이스틱으로도 진행 가능하도록 구현

### 타이틀화면(처음 화면)
- 버튼 구성
	- 게임 시작 
		- 저장소 목록 4개(로그 기능 아직 미구현)이며, 빈 칸 클릭 시 새로 시작한다(빈 칸은 '새로 시작'으로 작성되어 있다.).
	- 설정(필요한 목록이며, 이는 UI,UX를 고려하여 자연스럽게 구현하도록 한다.)
		- BGM(슬라이더로 구현한다.)
		- 효과음(슬라이더로 구현한다.)
		- 화면 모드(창모드, 전체화면 및 해상도)
		- 언어 설정
		- 텍스트 속도, 텍스트 크기
	- 나가기
