## SET-010 : 타이틀 화면(처음 화면)
- 버튼 구성
	- 게임 시작
		- 저장소 목록 4개(로그 기능 아직 미구현)이며, 빈 칸 클릭 시 새로 시작한다(빈 칸은 '새로 시작'으로 작성되어 있다.).
	- 설정 (→ SET-030)
	- 나가기

## SET-020 : 일시정지
- ESC 누를 시 일시정지 및 버튼 목록
- 버튼 구성
	- 돌아가기
	- 설정 (→ SET-030)
	- 나가기 : 확인 창을 띄운 뒤 타이틀 화면으로 돌아간다.

## SET-030 : 설정 항목 (타이틀·일시정지 공통)
필요한 목록이며, 이는 UI,UX를 고려하여 자연스럽게 구현하도록 한다.
- BGM(슬라이더로 구현한다.)
- 효과음(슬라이더로 구현한다.)
- 화면 모드(창모드, 전체화면 및 해상도)
- 언어 설정(지원 언어는 기본으로 한국어와 영어만 지원하며, 개발 완료 후 다른 언어 추가 검토 진행 예정)
- 텍스트 속도(5~120자/초, 기본 40, 최대치는 "즉시"로 처리)
- 텍스트 크기(작게 18 / 보통 22 / 크게 28px)

## SET-040 : 입력
- 클릭 or 스페이스바 = 게임 진행
- 방향키
- 조이스틱으로도 진행 가능하도록 구현

## SET-050 : 글꼴
- 재배포 가능한 글꼴(SIL OFL 1.1)만 쓴다. 파일은 `DoctorPlant/assets/fonts/<글꼴명>/`에 라이선스 파일과 함께 둔다.
- 용도별 글꼴

| 용도 | 글꼴 | 굵기 |
|---|---|---|
| 대사창 본문 (기본 글꼴) | 마루 부리 | Regular / Bold |
| 메뉴 · 설정 · 버튼 등 UI | Pretendard | Regular / SemiBold |
| HUD 숫자 · SYSTEM 문구 | 갈무리11 | Regular / Bold |
| 타이틀 · 챕터 카드 | 송명 | Regular |
| 손글씨 (진료 차트, 메모, 연구 노트) | 나눔손글씨 펜 | Regular |

- 갈무리는 도트 글꼴이라 11px의 정수배(22 · 33px)로만 쓴다. SET-030 텍스트 크기 설정의 영향을 받지 않는 곳에만 쓴다.
- 나눔손글씨 펜 · 송명에 없는 기호(… · → ▼ 등)는 마루 부리로 대신 표시한다.
- 배포할 때 각 글꼴의 라이선스 파일을 함께 넣고, 크레딧에 글꼴 이름을 적는다.
